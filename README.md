# Rezaei Store

وب‌اپ استاتیک و واکنش‌گرای فروشگاه رضایی با رابط فارسی راست‌چین، جست‌وجو، فیلتر دسته‌بندی و دکمهٔ سفارش واتساپ. فهرست محصولات از `products.json` خوانده می‌شود و تصاویر از پوشهٔ محلی `posters/` سرو می‌شوند.

## افزودن پوستر از موبایل یا دسکتاپ

1. پوشهٔ [posters](https://github.com/Ahmadbehzadi1998/RezaeiStore/tree/main/posters) را باز کنید.
2. از **Add file → Upload files** تصویر را بارگذاری و سپس **Commit changes** را انتخاب کنید.
3. بهتر است نام فایل انگلیسی و کوتاه باشد؛ برای نمونه `jacobs-gold-190g.webp`. فرمت WebP یا JPEG بهینه‌شده توصیه می‌شود.
4. فایل [products.json](./products.json) را باز کنید و با **Edit this file** یک محصول به آرایه اضافه کنید:

```json
{
  "nameFa": "جیکوبز گلد ۱۹۰ گرم",
  "nameEn": "Jacobs Gold 190g",
  "category": "قهوه",
  "image": "/posters/jacobs-gold-190g.webp",
  "alt": "پوستر محصول جیکوبز گلد ۱۹۰ گرم",
  "description": ""
}
```

این شیء باید داخل آرایهٔ JSON قرار بگیرد و بین محصولات، ویرگول‌ها درست باشند. مقدار `image` باید با مسیر و نام دقیق فایل بارگذاری‌شده یکسان باشد. پس از ثبت commit، Vercel به‌صورت خودکار نسخهٔ جدید را منتشر می‌کند.

**قیمت، موجودی یا ادعای محصول را حدس نزنید.** فقط اطلاعات تأییدشده را وارد کنید.

## فایل‌های پروژه

- `index.html` — ساختار صفحه و فراداده
- `styles.css` — طراحی واکنش‌گرا و انیمیشن‌ها
- `app.js` — بارگذاری کاتالوگ، جست‌وجو، فیلتر و لینک‌های واتساپ
- `products.json` — فهرست محصولات
- `posters/` — تصاویر محصولات
- `vercel.json` — سرآیندهای امنیتی HTTP

## امنیت و انتشار

این پروژه فرانت‌اند استاتیک و بدون پایگاه داده یا فرم ورود است. شمارهٔ واتساپ داخل کد عمومی است و نباید در آن اسرار یا کلید API قرار داده شود. سرآیندهای امنیتی در `vercel.json` تعریف شده‌اند. پس از هر تغییر، وضعیت انتشار Vercel و نمایش تصاویر را بررسی کنید.
