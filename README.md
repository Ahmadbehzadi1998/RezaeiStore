# Rezaei Store

وب‌اپ واکنش‌گرا و راست‌چین فروشگاه رضایی با طراحی روشن، جلوه‌های شیشه‌ای ملایم و انیمیشن‌های سبک. سایت از فایل `products.json` فهرست محصولات را می‌خواند.

## افزودن پوستر به‌صورت دستی از موبایل یا دسکتاپ

### ۱) بارگذاری تصویر
1. تصویر محصول را ترجیحاً با فرمت **WebP** یا **JPG** آماده کن. از نام فایل انگلیسی و کوتاه استفاده کن؛ برای مثال `jacobs-gold-190g.webp`.
2. پوشهٔ [posters](https://github.com/Ahmadbehzadi1998/RezaeiStore/tree/main/posters) را باز کن.
3. روی **Add file → Upload files** بزن.
4. تصویر را انتخاب کن، سپس **Commit changes** را بزن.
5. مسیر نهایی تصویر می‌شود: `/posters/jacobs-gold-190g.webp`.

### ۲) افزودن نام و مشخصات محصول
1. فایل [products.json](./products.json) را باز کن.
2. روی آیکون مداد (**Edit this file**) بزن.
3. یک شیء جدید به آرایه اضافه کن. برای مثال:

```json
[
  {
    "nameFa": "جیکوبز گلد ۱۹۰ گرم",
    "nameEn": "Jacobs Gold 190g",
    "category": "قهوه",
    "image": "/posters/jacobs-gold-190g.webp",
    "alt": "پوستر محصول جیکوبز گلد ۱۹۰ گرم",
    "description": ""
  }
]
```

4. نام فایل در فیلد `image` باید دقیقاً با نام فایلی که بارگذاری کردی یکسان باشد.
5. برای محصولات بعدی، بعد از `}` هر محصول و قبل از محصول بعدی ویرگول بگذار. کل فایل باید یک آرایهٔ JSON معتبر باشد.
6. روی **Commit changes** بزن.

**مهم:** فایل `products.json` در ابتدا عمداً خالی است. مثال بالا فقط قالب راهنما است؛ اطلاعات محصول را بر اساس پوستر واقعی وارد کن. قیمت، موجودی یا ادعای محصول اضافه نکن، مگر آن‌که خودت مشخص کرده باشی.

## ساختار پروژه

- `index.html` — رابط کاربری، جست‌وجو، فیلتر دسته‌بندی و کارت‌های محصول
- `products.json` — فهرست محصولات قابل ویرایش
- `posters/` — محل نگهداری تصاویر محصولات

## انتشار روی Vercel

مخزن را در Vercel به‌عنوان یک پروژهٔ استاتیک متصل کن. چون فایل‌ها در ریشهٔ مخزن هستند، نیازی به Build Command یا Output Directory نیست. پس از اتصال، هر commit جدید در شاخهٔ `main` می‌تواند باعث انتشار مجدد شود. برای استفاده از نشانی `rezaeistore.vercel.app` باید نام دامنه در Vercel آزاد باشد و پروژه به آن تخصیص داده شود.

## نکات تصویر
- برای نمایش سریع‌تر، از WebP و فایل‌های بهینه‌شده استفاده کن.
- نسبت تصویر پیشنهادی پوسترها: 4:5.
- نام فایل‌ها را انگلیسی، با حروف کوچک و خط تیره بنویس.
- از قرار دادن کلیدهای محرمانه، رمز عبور یا اطلاعات خصوصی در مخزن عمومی خودداری کن.
